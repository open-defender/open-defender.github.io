Защита Linux‑сервера. В одной программе.

Open Defender — EDR-агент с открытым кодом на Go. Обнаруживает перебор паролей к SSH, веб-приложениям и базам данных, следит за ресурсами и отслеживает активность через eBPF.

Быстрый старт

Скачайте бинарник для своей архитектуры и поместите его в /usr/bin/open-defender. Затем установите службу systemd, проверьте конфигурацию и посмотрите, какие мониторы включены.

Сборки релизов amd64 386 arm64 arm32

Инструкция по установке

Что отслеживает Open Defender

Агент обрабатывает события локально. Источники событий, пороги и белые списки задаются в /etc/open-defender/config.yaml.

Защита SSH

Считает неудачные попытки входа и может временно блокировать IP-адрес при превышении заданного порога.

Веб-приложения

Распознаёт разведку и перебор паролей по журналам веб-сервера. Белые списки исключают блокировку доверенных адресов.

Базы данных

Выявляет повторные ошибки аутентификации по событиям из syslog, systemd journal или журналов Docker.

Контроль ресурсов

Следит за порогами загрузки CPU и памяти и показывает процессы с наибольшим потреблением при перегрузке.

eBPF-мониторинг

Обнаруживает сканирование TCP- и UDP-портов через XDP. Для контроля запуска команд используется BPF LSM.

Экспорт событий

При включении экспорта отправляет события в Light Defender Dashboard по зашифрованному WebSocket-соединению.

Выберите режим реакции

Режимы настраиваются отдельно для SSH, веб-приложений, баз данных и совместимых eBPF-мониторов. В режиме наблюдения можно проверить срабатывания перед включением блокировки.

blocker
Обнаруживает события и применяет правила блокировки монитора.
logger
Записывает обнаруженные события в журнал.
disabled
Монитор выключен.

Автономная работа и Dashboard

Локальное обнаружение и блокировка продолжаются при недоступности панели. Экспорт позволяет собирать события с нескольких серверов и управлять конфигурацией агентов из Dashboard.
