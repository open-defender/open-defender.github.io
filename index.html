Linux server protection. In one agent.

Open Defender is an open-source EDR agent written in Go. It detects brute-force attempts against SSH, web apps and databases, monitors resources, and observes network and process activity with eBPF.

Quick start

Download the binary for your architecture and put it in /usr/bin/open-defender. Then install the systemd service, validate the configuration, and check which monitors are active.

Release builds amd64 386 arm64 arm32

What Open Defender monitors

The agent processes events locally. Set the event sources, thresholds, and allowlists in /etc/open-defender/config.yaml.

SSH brute force

Counts failed logins and can temporarily block the source IP when it reaches the configured threshold.

Web applications

Detects reconnaissance and brute-force patterns in web server logs. Allowlists help keep trusted addresses out of bans.

Databases

Detects repeated authentication failures from syslog, the systemd journal, or Docker logs.

Resource usage

Watches CPU and memory thresholds and reports the processes using the most resources under load.

eBPF monitoring

Detects TCP and UDP port scanning with XDP. Command execution control uses BPF LSM on compatible kernels.

Event export

Optionally sends events to Light Defender Dashboard over an encrypted WebSocket connection.

Choose how the agent responds

SSH, web, database and compatible eBPF monitors can be configured separately. Use logging to see what your rules match before enabling blocking.

blocker
Detects events and enforces the monitor’s blocking rule.
logger
Records matching events while allowing the activity.
disabled
Leaves the monitor switched off.

Run locally or connect Dashboard

Local detection and blocking keep running when Dashboard is unreachable. Enable the exporter to see events from several servers in one place and manage their agent configuration.
