Linux 服务器防护 一个代理即可

Open Defender 是用 Go 编写的开源 EDR 代理，可检测针对 SSH、Web 应用和数据库的暴力破解，监控资源消耗，并通过 eBPF 观察网络及进程活动。

快速开始 下载发布版本 源代码
  • Linux + systemd
  • MIT 许可证

快速开始

下载与系统架构匹配的二进制文件，将其放到 /usr/bin/open-defender。然后安装 systemd 服务，检查配置并查看启用的监控模块。

Open Defender 能监控什么

代理在本地处理事件。可在 /etc/open-defender/config.yaml 中配置事件来源、阈值和允许列表。

SSH 暴力破解

统计登录失败次数，达到配置的阈值时可临时封禁来源 IP。

Web 应用

通过 Web 服务器日志识别探测和暴力破解行为。允许列表可防止可信地址被封禁。

数据库

从 syslog、systemd journal 或 Docker 日志中检测反复出现的认证失败。

资源使用

监控 CPU 和内存使用阈值，并在负载过高时列出资源占用最高的进程。

eBPF 监控

通过 XDP 检测 TCP 和 UDP 端口扫描。在支持 BPF LSM 的内核上控制命令执行。

事件导出

启用导出后，通过加密的 WebSocket 连接向 Light Defender Dashboard 发送事件。

选择响应模式

SSH、Web、数据库和兼容的 eBPF 监控模块可分别选择模式。可以先记录事件，确认规则的匹配情况，再启用阻止功能。

blocker
检测事件并执行该模块的阻止规则。
logger
记录匹配的事件，允许相关活动继续。
disabled
关闭该监控模块。

本地运行与 Dashboard

Dashboard 无法连接时，本地检测和阻止功能仍会运行。启用导出功能后，可集中查看多台服务器的事件，并管理代理配置。
